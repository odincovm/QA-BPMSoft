# Результаты валидации страницы стажировки с помощью W3C

Сайт был проверен с помощью валидатора W3C, который проверяет, насколько страница соответствует стандарту HTML: [ссылка на результат](https://validator.w3.org/nu/?doc=https%3A%2F%2Fbpmsoft.ru%2Finternship%2F)

![w3c_report](../5.%20Images/w3c_report.png)

Всего ошибок в структуре HTML:
- 485 errors
- 148 warnings

Все ошибки можно сгруппировать по следующим категориям:

| № | Ошибка | Кол-во | Описание |
|---|---|---:|---|
| 1 | Дублирующиеся `id` | 143 | В HTML присутствуют повторяющиеся значения атрибута `id`. |
| 2 | Некорректные значения `autocomplete` | 112 | Используются недопустимые значения атрибута `autocomplete`, в частности `q` и `false`. |
| 3 | `div` внутри `label` | 105 | Элемент `div` используется как дочерний элемент `label`, что не соответствует правилам HTML в данном контексте. |
| 4 | Вложенные формы | 44 | Обнаружены ситуации, когда открывается новый `form` внутри уже открытого `form`. Вложенные формы не поддерживаются HTML. |
| 5 | `Stray end tag` | 24 | Обнаружены лишние или некорректно расположенные закрывающие теги (`noscript`, `head`, `form`). |
| 6 | Недопустимое использование атрибутов для `input` | 24 | Атрибуты `autocomplete` и `required` используются с типами `input`, для которых они не предусмотрены. |
| 7 | Недопустимые атрибуты элементов | 5 | Используются атрибуты, которые не разрешены для соответствующих элементов (`webkitallowfullscreen`, `mozallowfullscreen`, `placeholder`, `maxlength`, `required`). |
| 8 | Некорректные значения `id` в SVG | 5 | Значения `id` содержат недопустимые символы/формат, например `icon/56` и `Star 2`. |
| 9 | Дублирующиеся атрибуты | 5 | В отдельных элементах один и тот же атрибут указан более одного раза (`data-webformname`, `type`). |
| 10 | Некорректное использование `placeholder` | 5 | Атрибут `placeholder` используется с типами `input`, для которых он недопустим. |
| 11 | `CSS: Parse Error` | 2 | В CSS-коде присутствуют синтаксические ошибки, из-за которых часть стилей может обрабатываться некорректно. |
| 12 | Некорректные значения `width` и `height` у `iframe` | 2 | Значения `100%` не соответствуют допустимому формату HTML-атрибутов `width` и `height`. |
| 13 | Некорректное использование `maxlength` | 2 | Атрибут `maxlength` используется с типами `input`, для которых он недопустим. |
| 14 | Конфликт `meta` с `http-equiv="content-type"` и `meta charset` | 1 | В документе одновременно используются два способа указания кодировки страницы. Следует оставить один из них. |
| 15 | `Bad start tag in div in noscript in head` | 1 | Некорректное размещение элемента `div` внутри `noscript` в секции `head`. |
| 16 | Повторное открытие `body` | 1 | В документе открывающий тег `body` встречается повторно до закрытия предыдущего. |
| 17 | Некорректный `tel:` в `href` | 1 | В телефонной ссылке присутствует пробел. |
| 18 | У `img` отсутствует `alt` | 1 | Изображению не задан альтернативный текст `alt`, что снижает доступность страницы. |
| 19 | Некорректный `type` у `button` | 1 | Используется значение `type="secondary"`, которого нет среди допустимых значений атрибута `type` для `button`. |
