# 1. Баг-репорт
**Название:** При нажатии на кнопку «Перейти в Telegram» пользователю отправляется ссылка с истёкшим сроком действия.

**Шаги выполнения:**
1. Нажать на кнопку «Перейти в Telegram».
![bug-report1-step1](../5.%20Images/bag-report1-step1.png)
2. Открывается следующее окно при нажатии на "Join the group" — ничего не происходит.
3. При нажатии на "Open in web" появляется сообщение "This invite link has expired".
![bug-report1-step2](../5.%20Images/bag-report1-step2.png)

**Ожидаемый результат:** Пользователя перенаправляют в телеграм-канал BPMSoft.

**Фактический результат:** Появляется сообщение "This invite link has expired".
![bug-report1-result](../5.%20Images/bag-report1-result.png)

# 2. Баг-репорт
**Название:** При вводе некорректной почты кнопка «Подписаться» в подвале сайта становится кликабельной.

**Шаги выполнения:** Ввести в поле почту с неправильным доменом @gmail.co

**Ожидаемый результат:** Кнопка неактивна.

**Фактический результат:** Кнопка активна.
![bug-report2-result](../5.%20Images/bag-report2-result.png)
