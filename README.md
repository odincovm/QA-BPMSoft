# О проекте

Пет-проект по тестированию страницы стажировки компании BPMsoft.

Тестируемая страница: https://bpmsoft.ru/internship/

Цель проекта — проверить основные пользовательские сценарии, корректность работы интерактивных элементов и отображение страницы.

# Окружение
- ОС: Windows
- Браузер: Яндекс Браузер
- Доступ в интернет
