# Чек-лист: Шапка сайта

- [ ] Текст читаем и не сливается с фоном
- [ ] Никакие элементы не съезжают за границы, не наезжают друг на друга
- [ ] Все изображения корректно отображаются
- [ ] При наведении на кнопку "Главная" меняет цвет на белый
- [ ] При нажатии на кнопку "Главная" пользователя перенаправляют на главную страницу
- [ ] При наведении на кнопку "Отправить резюме" текст меняет цвет на черный
- [ ] При нажатии на кнопку "Отправить резюме" пользователя перенаправляют на форму отправки резюме
- [ ] Приветственное видео компании отображется корректно и воспроизводится
- [ ] При наведении на кнопку "Telegram подписаться" фон меняет цвет на черный
- [ ] При нажатии на кнопку "Telegram подписаться" пользователя перенаправляют в телеграмм канал BPMSoft
- [ ] Кнопки переключения картинок в блоке "Пространство BPMSoft" меняют фон на оранжевый при наведении
- [ ] Кнопки переключения картинок в блоке "Пространство BPMSoft" работают: картинки переключаются циклично
- [ ] Следующая картинка показывается в уменьшенном размене
- [ ] Кнопка вернуться наверх при наведении загорается оранжевым
- [ ] Кнопка вернуться наверх при нажатии возвращает на верх сайта

## Форма отправки заявки на стажировку
- [ ] При вводе в форму отправки заявки на стажировку цвет текста оранжевый, если введенное значение некорректно
- [ ] Обязательные поля отображаются * (кроме чекбокса на подачу согласия обработки данных) без них кнопка "Отправить" не активна
- [ ] Подать заявку можно без резюме
- [ ] При наведении на контактные адреса (телефон и почта) они меняют цвет на оранжевый
- [ ] При вводе номера телефона отображается флаг соответствующей страны
- [ ] Все поля в форме, кроме сопроводительного письма проверяют данные, которые вводит пользователь
- [ ] Если данные верны рядом с обязательными полями (кроме чекбокса на подачу согласия обработки данных)  появляется галочка
- [ ] При неправильном вводе данных появляется сообщение об ошибке
