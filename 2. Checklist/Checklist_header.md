# Чек-лист: Шапка сайта

## Проверка элементов шапки

- [ ] Все кнопки в шапке отображаются корректно
- [ ] При нажатии на логотип компании пользователя перенаправляют на главную страницу
- [ ] Все кнопки в шапке перенаправляют на соответствующие страницы
- [ ] При наведении на кнопки «Продукты», «Отрасли», «Экосистема», «Компания», они меняют цвет на оранжевый, и под ними появляется оранжевая полоска
- [ ] У кнопок «Продукты», «Отрасли», «Экосистема», «Компания» при наведении текст становится оранжевым
- [ ] При наведении фон кнопок "Заявка", "Демоверсия", "Войти" меняется на оранжевый
- [ ] У кнопки «Войти» текст кнопки становится белым

## Проверка поиска

- [ ] При наведении на лупу она меняет цвет на оранжевый
- [ ] При нажатии на лупу открывается поле для ввода текста для поиска с плейсхолдером «Поиск»
- [ ] При повторном нажатии на лупу поле для ввода скрывается
- [ ] При сворачивании поля поиска текст сохраняется
- [ ] При нажатии на Enter пользователя перенаправляют на страницу поиска
- [ ] Если поле поиска пустое, переход по Enter не работает
- [ ] Если слово в поле поиска не изменялось, переход по Enter не работает
