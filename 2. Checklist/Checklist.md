# Чек-лист: шапка сайта

## Проверка элементов шапки

- [ ] Все кнопки в шапке отображаются корректно.
- [ ] При нажатии на логотип компании пользователя перенаправляют на главную страницу.
- [ ] Все кнопки в шапке перенаправляют на соответствующие страницы.
- [ ] При наведении на кнопки «Продукты», «Отрасли», «Экосистема», «Компания» они меняют цвет на оранжевый, и под ними появляется оранжевая полоска.
- [ ] У кнопок «Продукты», «Отрасли», «Экосистема», «Компания» при наведении текст становится оранжевым.
- [ ] При наведении фон кнопок «Заявка», «Демоверсия», «Войти» меняется на оранжевый.
- [ ] У кнопки «Войти» текст становится белым.

## Проверка поиска

- [ ] При наведении на лупу она меняет цвет на оранжевый.
- [ ] При нажатии на лупу открывается поле для ввода текста для поиска с плейсхолдером «Поиск».
- [ ] При повторном нажатии на лупу поле для ввода скрывается.
- [ ] При сворачивании поля поиска текст сохраняется.
- [ ] При нажатии на Enter пользователя перенаправляют на страницу поиска.
- [ ] Если поле поиска пустое, переход по Enter не работает.
- [ ] Если слово в поле поиска не изменялось, переход по Enter не работает.









# Чек-лист: подвал сайта

- [ ] В левом блоке все кнопки при наведении становятся оранжевыми.
- [ ] При нажатии на кнопки они перенаправляют на нужные страницы.
- [ ] Кнопка «Заказать регистрацию» при наведении меняет цвет на чёрный.
- [ ] Кнопка «Заказать регистрацию» при нажатии открывает окно с заказом регистрации.
- [ ] Телефон и почта при наведении меняют цвет на белый.
- [ ] Кнопки социальных сетей при наведении меняют фон на чёрный.
- [ ] Кнопки социальных сетей при нажатии перенаправляют на соответствующий канал в социальной сети.
- [ ] При вводе своего email в специальное поле кнопка становится активной и подписывает почту на рассылку.
- [ ] При активации кнопки цвет текста становится ярче, а при наведении фон становится чёрным.
- [ ] При вводе некорректной почты кнопка неактивна.
- [ ] При попытке подписаться на рассылку несколько раз появляется сообщение о том, что нельзя подписываться сразу на две почты.
- [ ] Кнопки загрузки мобильного приложения при наведении подсвечиваются и ведут в соответствующие магазины приложений.
- [ ] Кнопки «Политика обработки персональных данных» и «Информированное согласие пользователя сайта» при наведении подсвечиваются в оранжевый цвет.
- [ ] Кнопки «Политика обработки персональных данных» и «Информированное согласие пользователя сайта» при нажатии переходят на соответствующие разделы сайта.
