# Чек-лист: Подвал сайта
- [ ] В левом блоке все кнопки текст при наведении становятся оранжевыми
- [ ] При нажатии на кнопки они перенаправляют на нужные страницы
- [ ] Кнопка "Заказать регистрацию" при наведении меняет цвет на черный
- [ ] Кнопка "Заказать регистрацию" при нажатии открывает окно с заказом регистрации
- [ ] Телефон и почта при наведении меняют цвет на белый
- [ ] Кнопки с соцсетями при наведении меняют фон на черный
- [ ] Кнопки с соцсетями при надатии пененаправляют на соответствующий канал в соц сети
- [ ] При вводе своего email в спецальное поле кнопка станоивится активной и подписывает почту на рассылку
- [ ] При активации кнопки цвет текста становится ярче и при наведении цвет фона становится черным
- [ ] При вводе некорректной почты кнопка неактивна
- [ ] При попытке ввести несколько раз подписаться на рассылку придет сообщение, о том, что нельзя подписываться сразу на 2 почты
- [ ] Кнопки на скачивание мобильного приложения при наведении подсвечиваются и введут в соответствующие магазины приложений
- [ ] Кнопки "Политика обработки персональных данных" и "Информированное согласие пользователя сайта" при наведении подсвечиваются в оранжевый
- [ ] Кнопки "Политика обработки персональных данных" и "Информированное согласие пользователя сайта" при нажатии переходят на соответствующие разделы сайта
