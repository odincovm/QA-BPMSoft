# Тест-план проекта BPMsoft: сайт компании

## 1. Вступление

Настоящий документ является тест-планом проекта BPMsoft: сайт компании.
В нём определено следующее:
- цели и объём тестирования (что входит и что исключено);
- критерии завершения тестирования;
- применяемые подходы и техники;
- необходимые ресурсы и окружение;
- график работ;
- роли и риски.

Документ служит основой для согласования ожиданий между заказчиком, разработкой и QA и используется для планирования, контроля и отчётности по тестированию.

## 2. Область тестирования

### 2.1 Функциональные области

- навигационное меню;
- кнопки перехода в социальные сети;
- пользовательский интерфейс и отображение страниц;
- интерактивные элементы;
- презентационное видео.

### 2.2 Нефункциональные проверки

- проверка HTML-страницы стажировки с помощью W3C HTML validation;
- проверка процента неиспользуемой статики на странице стажировки.

## 3. Не входит в область тестирования

- страницы, кроме страницы стажировки, расположенной по адресу https://bpmsoft.ru/internship/;
- подача заявления в форме на стажировку;
- регистрация на сайте;
- производительность и нагрузка;
- безопасность сайта;
- кроссплатформенное и кроссбраузерное тестирование;
- окно техподдержки;
- всплывающее окно с исследованием рынка CRM-систем 2026 от Фонда «Сколково».

## 4. Тестовые единицы

- страница стажировки;
- шапка сайта;
- подвал сайта;
- ссылки на внешние сервисы и социальные сети;
- видеопрезентация компании.

## 5. Test approaches (Подходы и техники)

В данном пет-проекте подразумевается небольшое smoke-тестирование, проверка HTML-разметки с помощью W3C Nu HTML Checker и проверка процента неиспользуемой статики.

## 6. Критерии завершения тестирования

- основные функциональные сценарии проверены;
- выявленные дефекты зафиксированы в баг-репортах;
- определено текущее состояние проверенных функций;
- результаты функциональных и нефункциональных проверок отражены в итоговом отчёте.

## 7. Задачи тестировщика

- составление тестового плана;
- составление чек-листа;
- проверка сайта по данному чек-листу;
- написание баг-репортов в случае нахождения багов;
- подведение итогов в общем отчёте.

## 8. Потребности в окружении

Требуется один ноутбук с браузером и доступом в интернет.

## 9. Персонал и обучение

Данный пет-проект будет выполнять один QA Intern. Дополнительные ресурсы для проведения тестирования не требуются.

## 10. Артефакты тестирования

- тест-план;
- чек-лист;
- баг-репорты;
- итоговый отчёт.

## 11. График

Срок данного пет-проекта: с 12.09.2026 по 13.09.2026.

## 12. Риски

- ограничение времени тестирования — из-за того, что времени мало, часть сценариев может быть не проверена;
- зависимость от внешних сервисов — Telegram может быть временно недоступен;
- ограничение доступа к системе — тестирование проводится только со стороны пользователя.
